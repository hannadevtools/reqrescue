# Security policy

ReqRescue processes network traces that may contain credentials and personal
data. Never attach a real HAR, token, cookie, private URL, or response body to a
public issue.

Report a suspected vulnerability privately to **devhanna661@gmail.com** with:

- the affected version or commit;
- a minimal synthetic reproduction;
- the expected and observed behavior;
- impact and suggested mitigation, if known.

Use synthetic values only. We will acknowledge a report within seven days.
